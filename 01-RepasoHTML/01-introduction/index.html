Introducción a la web

El desarollo front-end se encarga de crear la parte visual e interactiva de los sitios web. Las tegonolias son CSS, HTML y JAVASCRIPT

Las tecnologias principales son:

HTML

HTML es el lenguaje que se utiliza para crear y estructurar páginas web.

CSS

CSS es el lenguaje que se utiliza para dar estilo y diseño a las páginas web.

JavaScript

JavaScript es un lenguaje de programación que permite agregar interactividad y funciones a las páginas web.
